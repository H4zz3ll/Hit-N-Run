This project implements an HID functionality to the Arduino UNO R3 so it can act like a HID. 

This device was inspired in the backdoor device from the Watch Dogs 2 game.

<img width="243" height="183" alt="image" src="https://github.com/user-attachments/assets/1aafc172-28e7-4228-a479-200dba94f900" />



The implementation adds the functionality so you can plug into a PC and it gathers all the information and logs from the victim device, very easy to hide under a desk and leave it there for a time.
